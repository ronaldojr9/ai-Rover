Rover ERP October 2025 Release Notice

Features, updates, and bug fixes for Rover Desktop – .NET Client v2.4.0 and Web Client versions 2.17.0 & 2.18.0

October's releases span three versions — .NET Client v2.4.0, Web Client 2.17.0, and Web Client 2.18.0 — delivering smarter client behavior, custom highlight rules, improved error handling, and a significant round of stability fixes across both clients.

Release Summary

Rover Desktop .NET Client v2.4.0, Web Client versions 2.17.0 and 2.18.0 — Released October 2025. These releases introduce smarter defaults, custom list highlights, improved error messages, and multiple stability improvements across both clients.

.NET Client v2.4.0 – New Features

Grid Export to Excel

  • Any grid view in the .NET client can now be exported directly to Excel via right-click context menu
  • Export includes all visible columns with their current filter and sort applied
  • Column headers in the exported file match the display names shown in the grid

Print Dialog Memory

  • The client now remembers the last-used printer and settings per document type
  • Label printers, report printers, and document printers are tracked separately
  • Settings persist across sessions — no reconfiguration needed after logging out

Session Recovery

  • If the client loses connection and reconnects, unsaved form data is preserved
  • A reconnection banner notifies the user and offers a one-click option to resume the interrupted session

Web Client 2.17.0 – New Features

Custom List Highlights

  • Users can define color-coding rules for any list view in Rover Web
  • Rules can be based on any field in the list: status, date, value, flag, or combinations
  • Highlights apply to full rows, specific columns, or icon indicators
  • Rules can be personal or shared across a role
  • Priority-ordered rules with clear precedence for conflicting conditions

Smarter Defaults

  • Frequently used field values now persist as defaults per user per screen
  • Context-aware vendor catalog filtering on PO line entry
  • Predictive part number suggestions on order entry based on customer order history
  • Smart date defaults based on document context (vendor lead time, customer terms, production schedule)

Quick-View Panels

  • Hover over any customer, vendor, or part reference to see a summary card
  • Recent records sidebar with last 10 accessed records
  • Cross-module drill-through from any document reference

Web Client 2.18.0 – New Features

Improved Error Handling

  • All error messages rewritten in plain business language
  • Resolution guidance included with every error — what to check, what to change, who to contact
  • Form data preserved on error — no re-entry needed after fixing an issue
  • Administrator error log with 30-day history, full context, and filtering
  • Inline validation on more fields — errors caught earlier in the workflow

Inventory Enhancements

  • Batch bin transfer now available — move multiple items in a single session
  • Cycle count status dashboard shows counts in progress, completed, and approved by location
  • Item availability view expanded to show all warehouses and bins simultaneously

Bug Fixes (All Versions)

  • Fixed an issue in the .NET client where the quick-print function would occasionally send to the wrong printer after a printer driver update
  • Resolved a web client issue where custom list columns would reset to default width after a browser refresh
  • Fixed an incorrect available-to-promise calculation when multiple open sales orders existed for the same item and warehouse
  • Corrected a display bug in the production schedule view where work orders spanning midnight would appear on the wrong day
  • Fixed an intermittent error during AP invoice matching when PO lines had partial receipts across multiple receipt records
  • Resolved a performance issue on the customer aging report for organizations with more than 5,000 active customers

Upgrade Notes

Web Client 2.17.0 and 2.18.0 have been automatically applied for cloud-hosted customers. The .NET Client v2.4.0 installer is available through the Zumasys customer portal. On-premise customers should contact Zumasys support to schedule their web client upgrade.
