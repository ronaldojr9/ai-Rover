Rover ERP Master Class – Rover BI Power Users

In this Master Class, we dive into Rover BI with a hands-on walkthrough focused on real-world reporting workflows—from building clean, performant datasets to creating dashboards fast with Magic Visuals and AI-assisted development.

If you've been using Rover BI for basic reports but know there's more power under the hood — this Master Class was made for you. In February's session, we went deep on advanced Rover BI techniques: dataset design for performance, Magic Visuals for rapid dashboard creation, and how to use AI-assisted development to write and debug DAX expressions faster than ever.

What We Covered

This session focused on three areas: Dataset Architecture (building clean, fast, reusable datasets), Magic Visuals (generating dashboards in minutes using AI), and AI-Assisted Development (using the Rover AI assistant to write formulas, troubleshoot errors, and explain complex expressions).

Building Clean, Performant Datasets

The foundation of every great Rover BI dashboard is a well-structured dataset. In this session, we walked through how to design datasets that are fast to query, easy to maintain, and reusable across multiple reports.

Dataset Best Practices

  • Star schema design: Structure your datasets with a central fact table and connected dimension tables — this dramatically improves query performance at scale
  • Pre-aggregated measures: Calculate totals, averages, and ratios at the dataset level rather than in individual visuals — keep visuals simple and fast
  • Incremental refresh: For large transactional datasets, configure incremental refresh so only new or changed data is loaded — not the entire dataset every time
  • Shared datasets: Build a core dataset once and share it across multiple dashboards — changes to the underlying data model propagate automatically
  • Row-level security: Implement RLS at the dataset level to ensure each user sees only the data they're authorized to view

Connecting to Rover ERP Data

Rover BI connects natively to your Rover ERP data through the Rover Data Services layer. In the session, we demonstrated how to:

  • Select and filter which tables and views to include in your dataset
  • Build relationships between tables using ERP keys (customer IDs, part numbers, work order numbers)
  • Create calculated columns for derived fields that don't exist natively in the ERP (e.g., days late, margin %, on-time delivery rate)

Magic Visuals: Dashboards in Minutes

Magic Visuals is one of the most popular features in Rover BI — and for good reason. Instead of manually configuring chart types, axes, and formatting, Magic Visuals analyzes your dataset and generates a full dashboard layout automatically.

How Magic Visuals Works

  1. Select the dataset you want to visualize
  2. Choose the key metrics you want to highlight (revenue, open orders, on-time %, inventory turns)
  3. Rover BI's AI engine analyzes the data structure and automatically selects the most appropriate chart types
  4. A complete dashboard is generated — including KPI cards, trend lines, bar charts, and tables
  5. You refine and customize the generated layout to match your exact needs

In live testing during the session, participants went from a raw dataset to a fully functional executive dashboard in under 8 minutes — including a revenue trend chart, open order aging breakdown, and top customer summary table.

AI-Assisted Development

Writing DAX expressions and complex calculated measures can be a barrier for users who aren't data analysts by trade. Rover BI's AI assistant removes that barrier — you describe what you want in plain English, and the assistant generates the expression for you.

What the AI Assistant Can Do

  • Generate DAX measures: "Calculate the 12-month rolling average of monthly revenue" → the assistant writes the complete DAX measure
  • Explain existing formulas: Paste in a complex expression and ask the assistant to explain what it does in plain English
  • Debug errors: When a measure returns an error, the assistant identifies the issue and suggests a fix
  • Optimize slow measures: The assistant can review an existing measure and suggest performance improvements
  • Suggest related metrics: Based on your dataset, the assistant proactively suggests measures you might want to add

Live Demo Highlights

During the session, our instructor used the AI assistant to:

  • Build a year-over-year revenue comparison measure in under 2 minutes
  • Fix a broken CALCULATE expression that was producing incorrect results
  • Generate a complete set of KPI measures for an operations dashboard — on-time delivery, scrap rate, schedule adherence — from a single prompt
