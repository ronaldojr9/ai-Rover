January Demo Day: Flexible Web Workflows, Approval Logic & .NET Client Quality of Life Improvements

Our January Demo Day showcased some of the most requested features in recent memory — configurable approval workflows in Rover Web, powerful new workflow logic, and a wave of quality-of-life improvements for .NET client users.

Our January Demo Day brought together the Rover ERP team to walk through a packed slate of new capabilities. This post recaps the highlights — from a brand-new approval framework in Rover Web to meaningful daily-use improvements in the .NET desktop client.

What Was Covered

Three major areas were featured in the January Demo Day: Flexible Web Workflows (configurable multi-step processes directly in Rover Web), Approval Logic (route documents through configurable approval chains), and .NET Client Quality of Life Improvements (faster, smoother daily use of the desktop client).

Flexible Web Workflows

One of the most requested capabilities from our manufacturing and distribution customers is the ability to define and manage their own business workflows directly in Rover Web — without custom code or IT intervention. That's exactly what flexible web workflows deliver.

With this feature, administrators can build multi-step process flows tied to key business events: a new customer record is created, a purchase requisition is submitted, a work order changes status, a quality hold is applied. Each trigger can launch a configurable sequence of actions — notifications, record updates, document generation, or routing to an approval queue.

Key Capabilities

  • Event-based triggers: Kick off workflows automatically based on record creation, status changes, field values crossing thresholds, or manual user actions
  • Configurable steps: Chain together notifications, field updates, document attachments, task assignments, and approval requests in any order
  • Conditional branching: Route workflows down different paths based on data values — for example, orders over $10,000 go through a different approval path than standard orders
  • User and role assignment: Assign tasks and approvals to specific users, roles, or dynamically to the record owner or manager
  • Visibility and audit trail: Every workflow step is logged with a timestamp, user, and outcome — giving managers a complete audit trail of every process

The workflow builder is available in Rover Web's administration panel. No coding required — administrators configure workflows using a visual interface that reflects the actual sequence of steps.

Approval Logic

Tied closely to flexible workflows, the new approval logic framework gives organizations a structured way to route documents and decisions through defined approval chains. This is particularly valuable for purchasing controls, expense authorizations, and quality sign-offs.

Approval Chains

Organizations can define multi-level approval chains for any document type supported in Rover Web. A purchase order, for example, might require approval from the purchasing manager for orders under $5,000, the VP of Operations for orders between $5,000 and $25,000, and the CFO for anything above that threshold.

  • Dollar threshold routing: Automatically route documents to the appropriate approver based on value
  • Sequential vs. parallel approvals: Require approvers to sign off in sequence, or notify multiple approvers simultaneously and require all (or any) to approve
  • Escalation rules: If an approval isn't acted on within a configured timeframe, automatically escalate to a backup approver or manager
  • Delegation: Approvers can delegate their authority temporarily — for vacations or out-of-office periods — without leaving approvals stuck in the queue
  • Rejection with comments: Approvers can reject a document with a required reason, which is logged and visible to the submitter

Where Approvals Apply

The initial release of approval logic supports the following document types in Rover Web:

  • Purchase Requisitions and Purchase Orders
  • Sales Order overrides (discounts beyond standard thresholds)
  • Credit limit exceptions
  • Work order material substitutions
  • Quality holds and dispositions

Why This Matters for Manufacturers

Many of our customers have been managing approvals through email chains, printed forms, or verbal sign-offs. That creates compliance gaps, slows down operations, and makes audits painful. The new approval framework brings those controls directly into Rover ERP — where the data already lives — so approvals are fast, traceable, and enforceable.

.NET Client Quality of Life Improvements

While Rover Web continues to expand in capability, many Rover ERP users rely on the .NET desktop client for their day-to-day work — and this release includes a meaningful set of improvements that make the desktop experience faster and less frustrating.

Navigation & Search

  • Persistent search history: Search fields now remember recent lookups, so frequently-used part numbers, customer names, or vendors are a single click away
  • Improved tab behavior: Tab-key navigation between fields is smoother and more predictable across all major screens
  • Quick-access favorites bar: Users can pin their most-used screens to a persistent favorites bar at the top of the application — reducing menu navigation for everyday tasks

Data Entry & Display

  • Inline editing in grids: Select grid rows can now be edited inline without opening a separate detail screen — saving clicks for batch updates
  • Column resizing memory: Column widths and order are now saved per-user, per-screen — no more resizing the same grid every time you log in
  • Improved date pickers: Date entry fields now accept typed input more reliably, and the date picker calendar has been redesigned for clarity
  • Larger default font options: Users can select from three display density settings — Compact, Standard, and Comfortable — to match their screen size and preference

Performance

  • Faster screen loads: Several high-traffic screens (Customer Inquiry, Part Inquiry, Order Entry) have been optimized to load noticeably faster on both LAN and WAN connections
  • Reduced memory usage: Background data caching has been refactored — customers running the .NET client on older hardware should see improved stability over long sessions

What's Coming Next

The January Demo Day also included a sneak peek at capabilities on the near-term roadmap:

  • Workflow templates: A library of pre-built workflow templates for common manufacturing and distribution processes — import and customize rather than build from scratch
  • Mobile approval notifications: Push notifications to mobile devices when an approval action is waiting — keeping the approval queue moving even when approvers are on the floor
  • Expanded document coverage: Approval logic extended to cover additional document types including AP invoices and RMAs
  • Rover Web: Customer Portal improvements: Enhanced self-service capabilities for customers — order status, invoice history, and document downloads without calling in

How to Get These Features

Flexible web workflows and approval logic are available to all Rover ERP customers on Rover Web. Cloud-hosted customers will receive the update automatically. On-premise customers should contact Zumasys support to schedule their upgrade to the latest release.

The .NET client quality of life improvements are included in the latest desktop client installer, available through the Zumasys customer portal or by contacting your support representative.

If you'd like a guided walk-through of the new workflow and approval features — or want help designing workflows for your specific operations — schedule a session with our team. We're happy to help you design approval chains and workflows that match the way your business actually runs.
