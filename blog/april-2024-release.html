Rover ERP April 2024 Release Notice

The April 2024 release adds GL Journal Entry via Rover Web, post-creation pick ticket printing, user-based printer defaults, and real-time inventory visibility in part search.

The April 2024 release, posted May 3, 2024, continues Rover ERP's commitment to expanding Rover Web capabilities while improving day-to-day usability across the platform. This release (covering Web Client versions 2.1.0 through 2.4.0) brings four meaningful improvements: GL Journal Entry in the web interface, streamlined pick ticket printing, user-based printer defaults, and in-context inventory visibility during part search and order entry.

Finance: GL Journal Entry via Rover Web

A new GL Transaction entry screen is now available in Rover Web, bringing one of the most-requested accounting functions to the modern interface. Users can now enter new General Ledger journal entries without needing to open the legacy client.

  • Standard debit/credit entry with full account lookup — search accounts by number or description without memorizing codes
  • Supports all standard journal entry types including recurring entries and adjusting entries
  • Validation enforces balanced entries before submission, preventing unbalanced journals from reaching the ledger

This is part of an ongoing initiative to bring full accounting functionality to the Rover Web interface, reducing dependency on the legacy client for finance team workflows. Additional GL and AR/AP functionality is planned for upcoming releases.

Shipping & Fulfillment: Pick Ticket Improvements

Two related improvements make the order fulfillment workflow more efficient for warehouse teams:

Print on Creation

A pick ticket can now be printed immediately after order creation — without navigating to a separate print queue or returning to the order later. The moment an order is saved, the print prompt appears. For high-volume fulfillment operations, this eliminates a manual step from every single order.

User-Based Default Printer

Each user can now set a preferred default pick ticket printer in their personal Settings. Set it once and the system remembers it for every future order. Users working at different workstations or in different areas of the warehouse can each have their own default — so the right printer fires every time without any selection required at the moment of printing.

Small Change, Big Impact

In a fulfillment operation processing hundreds of orders per day, eliminating even one click per order adds up to hours of recovered time per week. These two pick ticket improvements work together to remove friction at the highest-frequency point in the fulfillment workflow.

Inventory Visibility: Part Search Enhancements

One of the most common interruptions in the order entry process is needing to check stock levels mid-order — navigating to a different screen, looking up the part, then navigating back. This release eliminates that interruption entirely.

  • Inventory in part search — on-hand quantities are now visible directly in the part search screen. No need to open a separate inventory inquiry.
  • Warehouse breakdown on click — clicking on the available quantity label expands a warehouse-by-warehouse breakdown, showing exactly where stock is located across your facility or facilities
  • Also available in cart view — the same inventory visibility is available in the POS/order entry cart, so you can check availability without leaving the order in progress

For customer service representatives and sales staff entering orders, this means faster answers to "do we have it?" without putting the customer on hold or switching screens.

Web Client Version History

This release encompasses Web Client versions 2.1.0 through 2.4.0. Here's what each version introduced:

Version Changes
2.1.0 Initial GL Journal Entry screen in Rover Web
2.2.0 Pick ticket default printer per user in Settings
2.3.0 Inventory quantities displayed in part search screen
2.3.1 Bug fixes and stability improvements
2.4.0 Inventory visibility extended to cart/order entry view

How to Update

Rover Web updates are deployed automatically for cloud-hosted customers — no action is required. If you're on the cloud, you already have these features.

On-premise customers should contact Zumasys support to schedule their upgrade. The support team will coordinate a maintenance window and handle the update process. If your organization is still running an on-premise instance and you'd like to explore the benefits of cloud hosting, reach out to our team — automatic updates are just one of many advantages.
