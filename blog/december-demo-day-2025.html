December Demo Day – Web Production Enhancements, POS Flexibility & .NET Client Quality-of-Life Improvements

This month's demo day focuses on user experience, data visibility, and system stability designed to help teams move faster, work smarter, and experience fewer interruptions.

December's Demo Day closed out 2025 with a strong set of improvements across three major areas: web-based production management, point-of-sale flexibility, and daily-use enhancements for .NET client users. Here's a full recap of what we showcased.

What Was Covered

Three major areas were featured: Web Production Enhancements (expanded shop floor capabilities in Rover Web), POS Flexibility (new configuration options for point-of-sale workflows), and .NET Client Quality-of-Life Improvements (faster, more reliable desktop experience).

Web Production Enhancements

Rover Web's production module continues to expand toward full feature parity with the .NET client. In December's release, we added several capabilities that production supervisors and shop floor managers have been requesting.

Work Order Management

  • Batch status updates: Select multiple work orders and update their status in a single action — no more updating each order individually
  • Inline operation completion: Mark individual routing operations as complete directly from the work order list view, without drilling into the detail screen
  • Production variance alerts: Visual indicators now flag work orders where actual quantities, labor, or material costs have deviated significantly from the estimate
  • Scrap reporting from the web: Scrap transactions can now be recorded directly in Rover Web, with reason codes and optional photo attachments

Shop Floor Visibility

  • New production dashboard shows real-time status across all open work orders: scheduled, in-progress, on-hold, and complete
  • Work center load view displays scheduled hours vs. available capacity by day for the next two weeks
  • Late order alerts surface work orders at risk of missing their due date based on current progress and remaining operations

POS Flexibility

Our point-of-sale module received significant configuration improvements this month, giving businesses more control over how their counter sales and service-desk transactions work.

New Configuration Options

  • Custom tender types: Define additional payment methods beyond cash and card — store credit, trade-in value, gift certificates, and account charges are all now configurable
  • Flexible discount controls: Set maximum discount percentages by user role, item category, or customer type — with override capability for authorized users
  • Configurable receipt templates: Design custom receipt formats including your logo, promotional messaging, and return policy language
  • Transaction holds: Put a POS transaction on hold to assist another customer, then retrieve and complete it without losing any entered data
  • Integrated customer lookup: Search for existing customers at POS by name, phone, or account number — apply loyalty pricing, terms, and account charges automatically

Reporting

  • End-of-day POS summary report now breaks down sales by tender type, item category, and cashier
  • Void and return transactions are now tracked separately in the daily report for clearer reconciliation

.NET Client Quality-of-Life Improvements

The December release included several targeted improvements to the .NET desktop client based on support feedback and user requests.

Usability Fixes

  • Print dialog memory: The client now remembers your last-used printer and print settings per document type — no more re-selecting the label printer every time you print a pick ticket
  • Grid export to Excel: Any grid view in the .NET client can now be exported directly to Excel using a right-click context menu option
  • Improved field validation: Required field indicators are now more visible, and validation errors are shown inline next to the offending field rather than in a separate popup
  • Session recovery: If the .NET client loses connection to the server and reconnects, unsaved work in forms is now preserved rather than discarded

Performance

  • The customer inquiry screen loads up to 40% faster on datasets with more than 10,000 active customers
  • Report generation for large date ranges has been optimized — monthly sales analysis reports that previously took 3–4 minutes now complete in under 60 seconds in most environments
