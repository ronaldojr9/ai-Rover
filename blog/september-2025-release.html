Rover ERP September 2025 Release Notice

Features, updates, and bug fixes for Rover Web Client version 2.16.0

Rover Web Client 2.16.0 focuses on warehouse operations, session security, and customer portal enhancements — building on the features showcased in September's Demo Day. Here's a complete summary of what's new and fixed.

Release Summary

Rover Web Client version 2.16.0 — Released October 2025. This release delivers enhanced barcode scanning, session security improvements, and expanded customer portal capabilities.

New Features

Enhanced Barcode Scanning

  • Barcode scanning now works in all Rover Web receiving, picking, and bin transfer screens — no separate scanning app required
  • Support for 1D and 2D barcodes (QR codes, DataMatrix) across all scanning workflows
  • Scan-to-confirm mode: Scan the barcode on a tote or carton to automatically confirm the pick — eliminates manual quantity entry for standard pick operations
  • License plate scanning: Receive entire pallets or totes by scanning a single license plate label
  • Mobile device optimization: Scanning screens automatically enter full-screen mode on mobile devices for easier use on tablets and handheld scanners

Session Security Improvements

  • Configurable session timeout: Administrators can set idle timeout durations by user role — shorter timeouts for warehouse users on shared devices, longer timeouts for office users on personal workstations
  • Session activity log: Administrators can view a log of active sessions including user, device, IP address, and last activity time
  • Force logout: Administrators can remotely terminate any active session from the session management screen
  • MFA enforcement by role: Multi-factor authentication can now be required for specific roles (administrators, managers) while remaining optional for other users
  • Login location restrictions: Optionally restrict logins to specific IP ranges or subnets — useful for organizations that want to prevent access from outside the facility

Customer Portal Enhancements

  • Order tracking timeline: Customers can now see a visual timeline of their order from entry through shipment, including key milestone dates
  • Document downloads: Invoices, packing lists, and proof of delivery documents are available for download directly from the portal
  • Return Request initiation: Customers can initiate a return request (RMA) from the portal — triggering the internal RMA workflow in Rover ERP
  • Notification preferences: Customers can manage their email notification preferences — what they want to be notified about and when
  • Consolidated account view: Multi-site customers can now view all their locations' orders under a single portal login

Improvements

Warehouse Operations

  • Pick confirmation screen redesigned for faster operation on mobile devices — larger touch targets, simplified layout
  • Receiving screen now shows previous receipts for the same PO inline — useful for identifying partial receipt situations
  • Bin location lookup improved — type partial bin code with wildcard support

General Web Client

  • Print preview now available before sending to printer — reduces wasted labels and paper
  • Column filter dropdowns now support multi-select — filter a list by multiple status values simultaneously
  • Saved views: Users can save their current filter and sort configuration on any list view and restore it with one click

Bug Fixes

  • Fixed an issue where session timeout warning would not appear for users on certain browser configurations, resulting in silent logouts
  • Resolved an incorrect quantity available calculation on the picking screen when multiple open orders existed for the same item
  • Fixed a customer portal issue where PDF invoices would occasionally download with corrupted formatting on Safari
  • Corrected an issue where barcode scans with leading or trailing whitespace would fail to match records
  • Fixed a display error in the bin transfer confirmation screen when transferring items with active lot tracking
  • Resolved an issue where customer portal users could see orders for other customers in certain multi-site configurations

Upgrade Notes

Web Client 2.16.0 has been automatically applied for cloud-hosted customers. On-premise customers should contact Zumasys support to schedule their upgrade. The new session security features require administrator configuration before taking effect.
