Rover ERP November 2025 Release Notice

Features, updates, and bug fixes for Rover Web Client versions 2.19.0 & 2.20.0

November saw two web client releases — 2.19.0 and 2.20.0 — delivering expanded production capabilities, AI support assistant enhancements, and a significant round of bug fixes. Here's a complete summary of what's included.

Release Summary

Rover Web Client versions 2.19.0 and 2.20.0 — Released November 2025. These releases expand the AI support assistant, improve web production workflows, and deliver broad quality fixes across the platform.

Version 2.19.0 – New Features

Rover AI Technical Support Assistant (Beta)

  • Initial release of the Rover AI Technical Support Assistant for internal support teams
  • Natural language queries against live ERP data — orders, invoices, inventory, vendor records
  • Role-based access control integrates with existing Rover security settings
  • Configuration available in Rover AI administration panel
  • Audit logging for all assistant queries and responses

Web Production – Work Order Enhancements

  • Scrap reporting now available in Rover Web, including reason codes and photo attachment support
  • Work order labor entry improved — direct entry of start/stop times with automatic duration calculation
  • Material issue screen updated to show current bin quantities inline
  • Subcontract operation status now visible on the work order routing screen

Customer Portal

  • Customers can now download copies of invoices, packing lists, and proof of delivery documents directly from the portal
  • New order tracking timeline view shows key milestones from order entry through shipment
  • Email notification preferences can now be managed by customers through the portal settings page

Version 2.20.0 – New Features

AI Support Assistant – General Availability

  • AI Technical Support Assistant promoted from beta to general availability
  • Customer-facing portal integration now available — embed the assistant in your customer portal for self-service support
  • Expanded query coverage includes RMAs, warranty claims, and service tickets
  • Response confidence indicators help users understand when to verify information with a human agent

Rover BI Enhancements

  • Magic Visuals feature released — generate complete dashboard layouts automatically from your dataset
  • AI-assisted DAX formula generation now available in the measure editor
  • Shared datasets can now be marked as certified — indicating they've been reviewed and approved for organization-wide use
  • Dashboard subscriptions: schedule automatic PDF delivery of any dashboard to email recipients on a daily, weekly, or monthly cadence

Improvements

Web Client

  • Navigation sidebar now supports collapsing to an icon-only mode for more screen space
  • List view column filters now support "not equal" and "is blank / is not blank" operators
  • Inline editing now available in the open PO line items grid
  • Date pickers now accept keyboard shortcuts: "T" for today, "+7" for 7 days from today, "-30" for 30 days ago

Finance

  • Journal entry screen now supports copy-and-paste from Excel for rapid data entry
  • Bank reconciliation now highlights unmatched transactions in a separate review queue
  • AP aging report now includes a column for expected payment date based on vendor terms

Bug Fixes (2.19.0 & 2.20.0 Combined)

  • Fixed an issue where the work order completion screen would occasionally submit duplicate transactions under high load
  • Resolved a display error in the inventory valuation report for items with multiple costing methods
  • Fixed a session handling bug that caused intermittent 401 errors for users behind certain proxy configurations
  • Corrected an issue where sales order line delivery dates would reset to today when saving an address override
  • Fixed broken pagination in the vendor history inquiry when filtering by date range and item simultaneously
  • Resolved an issue where dashboard filters would not apply correctly after refreshing the browser
  • Fixed a calculation error in the weighted average cost update for items received in multiple currencies

Upgrade Notes

Both 2.19.0 and 2.20.0 have been automatically applied for cloud-hosted customers. On-premise customers should contact Zumasys support to schedule their upgrade. The AI Technical Support Assistant requires additional configuration before activation — reach out to your implementation consultant for setup guidance.
