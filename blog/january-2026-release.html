Rover ERP January 2026 Release Notice

Features, updates, and bug fixes for Rover Web Client version 2.21.0

The January 2026 release of Rover ERP (Web Client version 2.21.0) delivers a focused set of new features, workflow improvements, and quality fixes across the platform. Here's a complete summary of what's included in this release.

Release Summary

Rover Web Client version 2.21.0 — Released February 2026. This release introduces flexible web workflows, approval logic, and a broad set of usability improvements across the platform.

New Features

Flexible Web Workflows

  • Administrators can now define multi-step business process workflows directly in Rover Web without custom code
  • Event-based triggers support record creation, status changes, field value thresholds, and manual user actions
  • Conditional branching routes workflows down different paths based on data values
  • Full audit trail on every workflow step, including timestamp, user, and outcome

Approval Logic Framework

  • Multi-level approval chains now available for Purchase Requisitions, Purchase Orders, and Sales Order overrides
  • Dollar threshold routing automatically sends documents to the appropriate approver based on value
  • Sequential and parallel approval modes supported
  • Escalation rules automatically reassign approvals that aren't acted on within a configured timeframe
  • Delegation allows approvers to transfer authority temporarily
  • Approval logic also covers credit limit exceptions, work order material substitutions, and quality holds

Customer Portal Enhancements

  • Customers can now view order status, invoice history, and download documents directly from the portal
  • Improved portal navigation with a redesigned dashboard layout
  • New self-service options reduce inbound support requests for order inquiries

Improvements

Web Client

  • Improved grid performance on large data sets — list views with thousands of records now load and scroll faster
  • Date range filters now persist across sessions in list views
  • Attachment previews now support PDF files in addition to images
  • Keyboard navigation improved across all modal dialogs
  • Search results now highlight matching text within results for faster scanning

Inventory & Warehouse

  • Bin transfer screen now supports batch processing — transfer multiple items in a single session
  • Physical inventory count sheets can now be exported to CSV
  • Lot and serial number lookup improved with partial-match search support

Purchasing

  • Vendor lead time is now displayed inline on the purchase order entry screen
  • PO line notes now carry forward to the receipt and AP invoice screens
  • Blanket purchase order release history now shows cumulative quantities ordered and received

Sales & Order Management

  • Quote-to-order conversion now copies all line-level notes and attachments
  • Shipping address override on orders is now tracked with a change log entry
  • Credit hold status now displays as a banner alert on the customer record

Bug Fixes

  • Fixed an issue where saving a record with a blank required field would clear other unsaved fields
  • Resolved a display bug in the AP aging report when filtering by multiple vendors simultaneously
  • Fixed incorrect tax calculation on orders with mixed taxable and non-taxable line items
  • Corrected a session timeout issue that would occasionally log users out mid-workflow
  • Fixed broken pagination on the open order inquiry screen when filtering by date range
  • Resolved an issue where emailed documents would sometimes attach an older version of the document
  • Fixed a UI overlap issue in the workflow configuration panel on smaller screen resolutions

Upgrade Notes

Rover Web Client 2.21.0 is available now for cloud-hosted customers — no action required, the update has been automatically applied. On-premise customers should contact Zumasys support to schedule their upgrade.

The new workflow and approval features require administrator setup before they are active for end users. See the Rover Knowledge Base or contact your implementation consultant for configuration guidance.
